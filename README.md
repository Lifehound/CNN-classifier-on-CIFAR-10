# CNN-classifier-on-CIFAR-10
The final project of the course Introduction to Machine Learning was created together with Marcus Persson and Richard Harnisch.
It is a small CNN model trained on the dataset CIFAR-10, with the goal of demonstrating how a simple CNN is implemented, trained, and evaluated.
Furthermore, it was interesting to see how it would hold up against a fine-tuned pre-trained model such as ResNet18.
The answers and the process can be found in the report pdf. The code behind it all is structured neatly in the notebook.
